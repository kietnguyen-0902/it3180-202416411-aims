## Lab 01
**1. Vì sao dùng `git mv`?**
Giúp Git ghi nhận hành động di chuyển/đổi tên, giữ nguyên lịch sử commit. `mv` thường làm đứt gãy lịch sử.
**2. `release/lab01` có phải baseline không?**
Có. Nó đóng băng trạng thái để nộp bài (baseline).
**3. Vì sao không commit thẳng master dù làm một mình?**
Để hình thành thói quen tuân thủ Release Flow. `master` thường bị chặn push thẳng, phải qua PR để kiểm soát rủi ro.
